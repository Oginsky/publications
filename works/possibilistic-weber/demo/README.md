# Демонстрация субградиентного метода для возможностной постановки задачи Вебера

Интерактивная веб-демонстрация поиска точки размещения в возможностной задаче Вебера. Позволяет задавать конфигурацию объектов, запускать субградиентный метод и сравнивать результаты расчёта.

## Стек

- JavaScript (ES-модули), HTML и CSS; Canvas/WebGL, SVG и Web Worker в браузере.
- Node.js — сборка и автоматические проверки.
- Python, NumPy и SciPy — генерация численных эталонов для проверок математической модели.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/model.mjs` | Математическая модель и алгоритм расчёта |
| `src/worker.mjs` | Фоновое выполнение расчёта |
| `src/app.mjs`, `src/renderer.mjs` | Логика интерфейса и визуализация |
| `src/shell.html`, `src/style.css` | HTML-шаблон и стили |
| `src/criterion-*.mjs`, `src/criterion-shell.html`, `src/criterion.css` | Интерактивное объяснение построения критерия |
| `src/build.mjs` | Сборщик автономной страницы |
| `src/check*.mjs` | Автоматические проверки |
| `src/*.json`, `src/*reference.py`, `src/sensitivity-mixed.py` | Численные эталоны и скрипты их пересчёта |
| `src/fonts/`, `src/vendor/anatomy/` | Шрифты, включённые зависимости и лицензии |
| `index.html` | Результат сборки; игнорируется Git |

## Сборка

Требуется Node.js с поддержкой ES-модулей (`.mjs`). Из корня репозитория перейдите в директорию демонстрации:

```powershell
cd works/possibilistic-weber/demo
```

Все последующие команды выполняются из этой директории.

Обычная сборка:

```powershell
node src/build.mjs
```

Создаёт или перезаписывает `index.html`. Сборщик встраивает JavaScript, CSS, геометрию, шрифты и тексты лицензий в один автономный HTML-файл. Правки вносятся в `src/`, после чего сборку нужно повторить.

Сборка с аудитом геометрии — `--audit`:

```powershell
node src/build.mjs --audit
```

Этот режим дополнительно проверяет геометрию учебного прибора, порядок перекрытий, перенос срезов в 492 положениях и переход от интегратора к сумме в 123 положениях. Он также собирает HTML; при обнаружении ошибок команда завершается с ненулевым кодом.

## Запуск

После сборки откройте `index.html` в браузере. Параметр адреса `?explain=criterion` открывает объяснение построения критерия.

После изменений повторите сборку и обновите страницу.

## Проверки

Сначала соберите HTML, затем запустите проверки:

```powershell
node src/check.mjs
node src/check-criterion.mjs
node src/check-nonradial.mjs
node src/check-hover.mjs
node src/check-worker.mjs
node src/check-design.mjs
```

| Скрипт | Что проверяет |
| --- | --- |
| `check.mjs` | Модель, шаги метода, остановку, валидацию и численные эталоны |
| `check-criterion.mjs` | Модель учебного прибора и построение критерия |
| `check-nonradial.mjs` | Несферические срезы, субградиенты и независимые минимумы |
| `check-hover.mjs` | Предпросмотр шага, историю расчётов, импорт и экспорт сцен |
| `check-worker.mjs` | Выполнение расчёта в фоновом обработчике |
| `check-design.mjs` | Собранный HTML, встраивание шрифтов и лицензий, структуру элементов интерфейса |

Проверки запускаются в Node.js и при ошибке завершаются с ненулевым кодом. Для дополнительной проверки геометрии используйте сборку с `--audit`.

### Пересчёт эталонов

Для обычной сборки и тестов достаточно сохранённых JSON-файлов. Если требуется пересчитать независимые численные эталоны, установите зависимости Python и запустите генераторы:

```powershell
python -m pip install numpy scipy
python src/reference.py
python src/sensitivity-reference.py
python src/sensitivity-mixed.py
python src/nonradial-reference.py
```

Генераторы перезаписывают соответствующие JSON-файлы в `src/`. После пересчёта проверьте изменения эталонов и повторите автоматические проверки.
