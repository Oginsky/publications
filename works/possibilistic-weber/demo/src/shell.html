Как читать пространство

Каждый холм — функция возможности πⱼ(x,y). Его горизонтальное сечение на высоте α — множество Aⱼ(α). В карточке объекта можно независимо выбирать профиль и форму срезов: круг, эллипс или прямоугольник. Пропорция k задаёт отношение осей v/u; θ поворачивает их в плоскости. Масштаб a относится к оси u, по оси v он равен ak. Вертикальная координата показывает возможность, а не третью пространственную координату задачи.

Центры можно перетаскивать. «＋ Aⱼ» и двойной щелчок добавляют объект в произвольном месте. Щелчок по центру объекта или выбор в списке «Объекты» открывает его карточку. В ней доступны координаты, вес, масштаб и индивидуальный профиль. Клик вне объекта и карточки скрывает её; значения сохраняются. Профиль и показатели можно развернуть внутри карточки.

Щелчок на свободном месте или инструмент x₀ задаёт старт. «Новый старт» сохраняет прежние траектории; смена параметров алгоритма также сохраняет запуски вместе с их настройками. «3 старта» запускает сравнение из трёх мест. Во вкладке «Сходимость» можно просматривать отдельные итерации. Изменение объектов сбрасывает старые запуски; при смене p запуски остаются в списке с указанием p.

Кнопка «Анализ» открывает боковую панель с расстояниями, сходимостью и запусками. Её содержимое прокручивается отдельно, сцена остаётся рядом. Шестерёнка в правом верхнем углу графика открывает настройки отображения и камеры. Список объектов также открывается отдельно; все панели можно закрыть кнопкой × или Escape.

«Субградиент» показывает направление −g под курсором в режиме «Выбор». Длина этой стрелки масштабирована для наглядности. «Следующий шаг x⁺» показывает фактический шаг x⁺ = x − η₀g/(k + 1): до запуска из точки под курсором при k = 0, после запуска — из просматриваемой итерации выбранного расчёта. Наведение не меняет старт, результат и шаг выбранного запуска. Оба отображения доступны для всех форм срезов.

Математика

Для любых поддерживаемых форм Rⱼ(x,α) = maxₐ∈Aⱼ(α) ‖x − a‖, Dₚ = (∫Rⱼᵖ dα)¹⁄ᵖ. Для эллипса решается задача глобально дальней точки; для прямоугольника выбирается наиболее удалённый угол. При p = ∞ используется весь внешний срез, а не конечный набор α. Сферические dⱼ, rⱼ, mⱼ, sⱼ² для несферических объектов не определяются и показаны прочерками.

Для всех форм срезов используется обычный субградиентный метод: xᵏ⁺¹ = xᵏ − η₀gᵏ/(k + 1), gᵏ ∈ ∂Fₚ(xᵏ). При p = 2 это формулы (11)–(12) статьи; для остальных p используется субградиент соответствующего Fₚ. Параметры расчёта задают алгоритм, η₀, точность, лимит итераций и использование редукции. Сейчас доступен один алгоритм — субградиентный. При выключенной редукции даже круговые срезы обрабатываются общей формулой через дальние точки и квадратуру. В смешанной сцене редукция применяется только к круговым объектам.

В негладких точках выбирается допустимый субградиент: для кругового объекта в его центре — нулевой вклад, для нескольких дальних точек допускается усреднение их вкладов. Предварительного поиска оптимального центра нет. Проверка сходимости использует оценку из субградиентного неравенства: ε ≤ ‖g‖ maxⱼ‖x − cⱼ‖ для круговых сцен и ε ≤ ‖g‖ · 2Fₚ/Σβⱼ для общих центрально-симметричных срезов. Последняя следует из Dₚ(x̂,Aⱼ) ≥ ‖x − cⱼ‖ и Fₚ(x*) ≤ Fₚ(x). Оценка может быть завышена вблизи негладкого минимума.

Для круговых срезов Dₚ(x̂,Aⱼ) = (∫₀¹(dⱼ+rⱼ(α))ᵖ dα)¹⁄ᵖ. Суммируются сами метрики с весами βⱼ. Показатель p задаёт агрегацию по уровням α; расстояние dⱼ = ‖x − cⱼ‖ на плоскости остаётся евклидовым при любом p. Для сферических срезов при p = 1 и при p = ∞ с ограниченными профилями неопределённость добавляет константу к обычной задаче Вебера; единственность тогда может отсутствовать.

Вычислитель поддерживает вещественные 1 ≤ p ≤ 64 и p = ∞. Для колоколообразного профиля π(r) = 1/(1+(r/a)ᑫ) конечность Dₚ требует p < q. При p = ∞ гауссов, экспоненциальный и колоколообразный профили дают бесконечную метрику. Это свойство модели, а не ошибка вычисления.

Масштаб нечёткости a меняет радиусы всех срезов объекта. Верхний ползунок α выбирает только видимое сечение; в критерии интегрируются все уровни, поэтому этот ползунок не меняет решение. После изменения a, профиля, веса, центра или p нужен новый запуск. До него показана начальная точка, а прежние решения при других p доступны во вкладке «Запуски».

Для сферических срезов при p = 2: D₂ = √(d² + 2md + s²), m = ∫₀¹r(α)dα, s² = ∫₀¹r(α)²dα. Для треугольного профиля m = a/2, s² = a²/3. Поэтому масштаб входит и в значение критерия, и в его производную (d + m)/D₂. Это может менять минимум, но не обязано менять его в каждой конфигурации.

Например, у двух сферических объектов с равными весами и одной формой радиального профиля при p > 1 точка x* = (a₂c₁ + a₁c₂)/(a₁ + a₂) не зависит от p. Сохранение этой точки при изменении p корректно. При постоянном радиусе («Чёткий шар»), совпадающих центрах или выполнении условия оптимума в центре изменение параметров также может не сдвигать решение.

Что именно вычисляется

При включённой редукции круговые срезы используют точную формулу D₂ для p = 2, моменты радиуса для остальных целых p и квадратуру для дробных p. Без редукции для конечного p вычисляются Dₚ и субградиент общей формулой по срезам; при p = ∞ берётся внешний срез. Точность ε относится к оптимизации, без интервальной гарантии округлений и квадратуры. Малое перемещение само по себе не означает достижения ε. При исчерпании лимита расчёт явно сообщает, что точность не достигнута; в списке запусков сохранена лучшая найденная точка. При точных субградиентах график ηₖ = η₀/(k + 1) удовлетворяет условиям теоремы 2. Численная квадратура требует отдельного контроля погрешности для строгой гарантии сходимости.

Поверхности неограниченных профилей показаны до уровня π = 0,005; низкий край затухает. В Dₚ интегрируется весь профиль, хвосты не отбрасываются. Геометрия поверхности и поле Fₚ дискретизированы только для отображения. Цвета различают объекты и значения; возможность не трактуется как вероятность.
