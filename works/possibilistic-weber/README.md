# Возможностная постановка задачи Вебера

Сопровождающая программная реализация: интерактивная демонстрация возможностной задачи Вебера и субградиентного алгоритма расчёта.

Демонстрация позволяет настраивать объекты и их α-срезы, запускать расчёт, сравнивать траектории и исследовать построение критерия.

- [Открыть демонстрацию на GitHub Pages](https://oginsky.github.io/publications/possibilistic-weber/demo/).
- [Демонстрация: стек, сборка, запуск и проверки](demo/README.md).
